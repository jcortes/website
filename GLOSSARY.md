# Jorge Cortes · professional site

A bilingual site that sells independent software and DevOps services and
turns visitors into booked calls.

## Audience and conversion

**Ideal Client**:
A startup or small tech company with no dedicated DevOps person, which still
deploys by hand and is afraid of breaking production. All home page copy is
written to this reader.
_Avoid_: Empresas, companies, customers (as a generic audience)

**Primary CTA**:
Booking the free 30-minute call: the one action the site asks for. It is the
only element given the accent color and visual elevation.
_Avoid_: Main button, call to action (for anything else)

**Accent**:
The single high-contrast color, reserved for things the visitor can click,
above all the Primary CTA. Never decorative.
_Avoid_: Brand color, highlight color

## Offering

**Gig**:
One service offered, described by the problem it solves, with exactly three
Packages.
_Avoid_: Service (in code and content), product, offer

**Package**:
One of a Gig's three scope tiers: Basic, Standard or Premium.
_Avoid_: Plan, tier, level

**Related work**:
A past project shown on the Gigs it demonstrates; clients may stay anonymous.
_Avoid_: Portfolio, case study
